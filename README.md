# Agent Tools

A small Next.js site of browser-based calculators for AI coding agents, token costs, context windows, MCP tools, and instruction files.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run start
```

## Deploy

The app is designed for GitHub-connected deployment on Vercel. Update `lib/site.ts` and `app/robots.ts` with the final production domain before submitting the sitemap to Google Search Console.

## Important

Model prices are editable estimates and must be checked against official provider pricing. The calculators do not upload source code.
